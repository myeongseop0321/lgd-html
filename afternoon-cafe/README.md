# 오후의 여백

가상의 동네 카페를 위한 반응형 랜딩페이지입니다. 별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

- `index.html`: 브랜드 이야기, 메뉴, 가격, 방문 정보
- `style.css`: 모든 스타일과 모바일 반응형 설정. 맨 위 `:root`에서 색상을 변경합니다.
- `assets/coffee.jpg`: 메인 커피 사진
- `assets/together.jpg`: 브랜드 스토리 사진

외부 라이브러리, JavaScript, 웹 폰트 없이 구성했습니다. 이미지도 로컬에 저장해 인터넷 연결 없이 페이지를 볼 수 있습니다. 메뉴와 내비게이션은 페이지 안의 해당 영역으로 이동합니다.
